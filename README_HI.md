# Sunny AI — Test + Secure Backend

## अभी तुरंत टेस्ट
`sunny_ai_test.html` खोलें। यह local demo mode में चलता है और Creator/Owner पहचान के सवालों का जवाब देता है।

## असली AI backend
1. Node.js इंस्टॉल करें।
2. इस folder में `npm install` चलाएँ।
3. `.env.example` को `.env` बनाकर अपनी secret API key डालें।
4. `npm start` चलाएँ।
5. HTML में `ENDPOINT` को अपने `/api/chat` URL पर सेट करें।

API key कभी HTML/Blogger में न डालें।
